Increase TikTok Frequency to 3–4x/Week
Currently posting 2.6 videos/month — far below the minimum for TikTok growth. The production quality is already there. The bottleneck is volume. More content = more For You Page distribution.

Run Instagram Reels Ads — Riyadh Targeted
